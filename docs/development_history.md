# Public development history

This repository was publicly launched on 2026-07-20 as a sanitized source export derived from prior
private research development. The private repository contained restricted audit records, local paths,
and non-public checkpoints, so its Git history was not rewritten or published. Instead, the public
project begins with an honest initial commit containing only reviewed, redistributable source,
tests, and documentation.

Private development time is not counted as public incubation. Public issues, pull requests,
releases, external installation reports, and community feedback after 2026-07-20 constitute the
auditable public history. The original private repository remains separate and is not a dependency.
