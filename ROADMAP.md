# Roadmap

The project entered public incubation on 2026-07-20. Roadmap items are tracked as GitHub issues;
completion is evidence-driven rather than date-driven.

## Incubation objectives

1. Obtain reproducible clean-install reports from users outside the original development machine.
2. Add one executable public empirical demonstration without expanding scientific claims.
3. Stabilize the Python and CLI APIs across the supported Python matrix.
4. Improve documentation in response to user feedback.
5. Complete a current state-of-the-field comparison for the methods/software paper.
6. Exercise multiple tagged releases and archive a stable release with a DOI.
7. Complete the JOSS checklist only after sustained public use and issue-based development.

The earliest internal readiness review is 2027-01-20, six months after the actual public launch.
That date is a project target, not a claim about any journal eligibility rule or guaranteed
submission.
